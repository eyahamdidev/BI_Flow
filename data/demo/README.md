# Demo data (committed, small, public)

- `bike_share/daily-bike-share.csv`: UCI Bike Sharing Dataset (Fanaee-T & Gama, 2013; Capital Bikeshare, Washington DC,
  2011-2012), daily rows, via the public Microsoft `ml-basics` mirror. In this mirror `rentals` = casual riders only.
  License: CC BY 4.0 (UCI Machine Learning Repository).
- The 1% Olist sample used by `--dataset olist_sample` lives in `tests/fixtures/olist_sample/` (made by
  `scripts/make_sample.py` from the Kaggle dataset `olistbr/brazilian-ecommerce`, CC BY-NC-SA 4.0).
